&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Existing peer-to-peer networks are monolithic — all participants operate in a single space with common rules. Creating isolated spaces within a single network with their own access rules, hierarchy, and parameters requires either separate infrastructure or compromises in security.

## The Challenge

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Different applications of peer-to-peer networks require different parameters: a corporate network needs access control, a civic initiative needs anonymity, a state registry needs verifiability. Combining all these requirements in a single network without mutual influence was impossible. Creating each new application required deploying separate infrastructure.

## The Solution

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;An architecture has been developed that allows the creation of an unlimited number of architecturally isolated subnets of any scale on top of a single base network. Each subnet is autonomous — it has its own hierarchy parameters, its own participant authentication rules, and its own operational logic. Subnets do not affect each other and have no access to the data of other subnets. Creating a new subnet does not require deploying new infrastructure.
